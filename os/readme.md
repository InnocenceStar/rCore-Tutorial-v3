


## pte & pt

```
PageTable（页表管理器）
│
│  持有一个 root_ppn（根页表的物理页号）
│
├── 根页表（物理页，包含 512 个 PTE）
│     ├── PTE[0]  → 指向第二级页表 或 存映射
│     ├── PTE[1]  → ...
│     └── PTE[511]
│
├── 第二级页表（物理页，包含 512 个 PTE）
│     ├── PTE[0]  → 指向第三级页表 或 存映射
│     └── ...
│
└── 第三级页表（物理页，包含 512 个 PTE）
      ├── PTE[0]  → 存最终映射（VPN → PPN）
      └── ...
```
